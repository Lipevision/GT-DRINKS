# 🚨 CONVERSÃO URGENTE - IMAGENS HEIC PARA JPG

## ⚠️ PROBLEMA IDENTIFICADO

As imagens **IMAGEM 1.HEIC até IMAGEM 7.HEIC** estão em formato Apple HEIC.
**Navegadores NÃO conseguem exibir este formato.**

## ✅ SOLUÇÃO MAIS RÁPIDA (2 minutos)

### OPÇÃO 1: Windows Photos (Recomendado)

1. Abra a pasta: `c:\Users\ERICK CARTMAN\Desktop\GT DRINKS\images`
2. Para cada arquivo HEIC (7 no total):
   - **Clique duas vezes** na imagem (abre no app Fotos)
   - Clique nos **3 pontos (...)** no canto superior direito
   - Selecione **"Salvar como"** ou **"Exportar"**
   - Escolha formato **JPEG**
   - Salve com o mesmo nome: `IMAGEM 1.jpg`, `IMAGEM 2.jpg`, etc.

### OPÇÃO 2: Conversor Online (Mais Rápido)

1. Acesse: **https://convertio.co/pt/heic-jpg/**
2. Clique em **"Escolher arquivos"**
3. Selecione TODOS os 7 arquivos HEIC de uma vez
4. Aguarde a conversão automática (30 segundos)
5. Clique em **"Baixar Tudo"** (vai baixar um ZIP)
6. Extraia o ZIP na pasta `images`
7. **RENOMEIE** os arquivos mantendo os nomes exatos:
   - `IMAGEM 1.jpg`
   - `IMAGEM 2.jpg`
   - `IMAGEM 3.jpg`
   - `IMAGEM 4.jpg`
   - `IMAGEM 5.jpg`
   - `IMAGEM 6.jpg`
   - `IMAGEM 7.jpg`

### OPÇÃO 3: Script Automático PowerShell

1. Clique com **botão direito** no arquivo `CONVERTER_HEIC_PARA_JPG.ps1`
2. Selecione **"Executar com PowerShell"**
3. Siga as instruções na tela
4. O script abrirá cada imagem e pedirá para você salvar como JPG
