## 🔧 Como Adicionar

### Opção 1: Copiar Diretamente
1. Localize as imagens originais no seu computador
2. **Renomeie** cada arquivo com o nome exato listado acima
3. Copie todos os arquivos para a pasta: `images/`
4. Confirme que os nomes estão **exatamente iguais** (incluindo parênteses e números)

### Opção 2: Converter HEIC (se aplicável)
Se suas imagens estão em formato HEIC (iPhone):

1. Use um conversor online: [heictojpg.com](https://heictojpg.com/)
2. Faça upload dos arquivos HEIC
3. Baixe as versões JPEG
4. Renomeie conforme a lista acima
5. Copie para a pasta `images/`

## 🔄 Otimização de Imagens

Para melhor performance, otimize as imagens antes de adicionar:

### Ferramentas Recomendadas:
- **TinyJPG:** [tinyjpg.com](https://tinyjpg.com/) - Reduz tamanho sem perder qualidade
- **Squoosh:** [squoosh.app](https://squoosh.app/) - Compressor avançado
- **ImageOptim:** Para Mac
- **RIOT:** Para Windows

### Processo:
1. Abra a ferramenta
2. Faça upload da imagem
3. Ajuste qualidade para 85-90%
4. Baixe a versão otimizada
5. Use essa versão no site

## 🚨 Problemas Comuns

### Imagem não aparece?
- Verifique o nome do arquivo (incluindo parênteses)
- Confirme que está na pasta `images/`
- Limpe o cache do navegador (Ctrl+Shift+Delete)
- Verifique se a extensão é `.jpeg` (não `.jpg`)

### Imagem aparece distorcida?
- Verifique a proporção original da foto
- Use imagens com mínimo 1200px de largura
- Evite imagens muito pequenas

### Site carrega lento?
- Otimize as imagens (veja seção acima)
- Reduza tamanho dos arquivos para < 500KB
- Use formato JPEG com qualidade 85%
