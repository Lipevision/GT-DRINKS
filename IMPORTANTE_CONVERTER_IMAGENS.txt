  🛠️ MÉTODO 1: WINDOWS 11/10 (FOTOS)
═══════════════════════════════════════════════════════════════════════

Passo a passo para cada arquivo:

1. Vá para a pasta: GT DRINKS\images\
2. Clique com botão DIREITO no arquivo .HEIC
3. Selecione "Abrir com" → "Fotos"
4. Na parte superior, clique nos 3 pontinhos (...)
5. Selecione "Salvar como"
6. Em "Tipo", escolha "JPEG"
7. Salve com o MESMO NOME, trocando .HEIC por .jpg
   Exemplo: IMG_2764.HEIC vira IMG_2764.jpg
8. Repita para os 7 arquivos

═══════════════════════════════════════════════════════════════════════
  🛠️ MÉTODO 2: CONVERSOR ONLINE (MAIS RÁPIDO)
═══════════════════════════════════════════════════════════════════════

OPÇÃO A - Convertio (Recomendado):
1. Acesse: https://convertio.co/pt/heic-jpg/
2. Clique em "Escolher arquivos"
3. Selecione os 7 arquivos .HEIC de uma vez
4. Clique no botão vermelho "CONVERTER"
5. Aguarde a conversão (leva 1-2 minutos)
6. Clique em "Baixar" (vai baixar um .zip)
7. Extraia o .zip
8. Copie os 7 arquivos .jpg para GT DRINKS\images\
9. Substitua ou mantenha junto com os .HEIC

OPÇÃO B - CloudConvert:
1. Acesse: https://cloudconvert.com/heic-to-jpg
2. Arraste os 7 arquivos .HEIC para a janela
3. Clique em "Start Conversion"
4. Baixe os arquivos convertidos
5. Coloque na pasta images/

OPÇÃO C - HEICtoJPEG (Ferramenta dedicada):
1. Acesse: https://heictojpeg.com/
2. Arraste os 7 arquivos
3. Aguarde conversão automática
4. Baixe os arquivos .jpg

P: Posso usar PNG em vez de JPG?
