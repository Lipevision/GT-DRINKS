# GT DRINKS - Site Institucional

Site institucional premium para GT DRINKS, especializada em bartender e serviços de coquetelaria para eventos.

## 🎨 Identidade Visual

- **Cores principais**: Preto (#000000), Verde Neon (#00ff88), Branco (#ffffff)
- **Tipografia**: Montserrat (corpo), Playfair Display (títulos)
- **Estética**: Premium, sofisticada e contemporânea

## 📋 Estrutura do Site

1. **Cabeçalho** - Logotipo e menu de navegação responsivo
2. **Banner Principal** - Hero section impactante
3. **Apresentação** - Sobre a GT DRINKS
4. **Thiago** - Fundador e responsável
5. **Serviços** - Bartender e coquetelaria para eventos
6. **Galeria** - Fotos de drinks e eventos com filtros
7. **Carta de Drinks** - Cardápio com categorias
8. **Diferenciais** - O que torna a GT DRINKS única
9. **Orçamento** - Formulário de contato
10. **Rodapé** - Informações e redes sociais

## 🖼️ Imagens Necessárias

Para completar o site, adicione as seguintes imagens na pasta `images/`:

### Essenciais:
- **hero-bg.jpg** - Imagem de coquetéis para o banner principal (1920x1080px)
- **favicon.png** - Ícone do site (32x32px ou 64x64px)

### Recomendadas:
- Foto do logotipo GT DRINKS
- Foto do Thiago (fundador)
- Fotos de drinks preparados
- Fotos de eventos realizados
- Fotos do setup de bar

### Especificações:
- **Formato**: JPG para fotos, PNG para logotipo/favicon
- **Qualidade**: Alta resolução, otimizadas para web
- **Orientação**: Paisagem para banner e eventos, quadrada para drinks
- **Tamanho recomendado**: 1200-2000px de largura

## 🚀 Como Usar

### Desenvolvimento Local:
1. Abra o arquivo `index.html` em um navegador moderno
2. Ou use um servidor local como Live Server (VS Code)

### Publicação no GitHub Pages:
1. Crie um repositório no GitHub
2. Faça upload de todos os arquivos
3. Vá em Settings > Pages
4. Selecione a branch main/master
5. O site estará disponível em: `https://[seu-usuario].github.io/[nome-repositorio]`

## 🔧 Personalização

### Alterar Cores:
Edite as variáveis CSS em `css/styles.css`:
```css
:root {
    --color-black: #000000;
    --color-neon: #00ff88;
    --color-white: #ffffff;
}
```

### Adicionar Mais Drinks:
Copie e cole a estrutura de `.drink-card` no HTML

### Adicionar Mais Fotos na Galeria:
Copie e cole a estrutura de `.gallery-item` com o atributo `data-category` apropriado
