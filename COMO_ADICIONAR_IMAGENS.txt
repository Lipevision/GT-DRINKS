Você provavelmente tem as imagens com nomes parecidos.
Você precisa RENOMEAR ou COPIAR com o nome exato.

EXEMPLOS DE CONVERSÃO:

Se você tem:              Renomeie para:
────────────────────      ──────────────────
IMG_1319.jpg        →     IMG_1319(5).jpeg
IMG_1319(5).jpg     →     IMG_1319(5).jpeg
IMG_1318.jpeg       →     IMG_1318(3).jpeg
IMG1317.jpg         →     IMG_1317(3).jpeg

═══════════════════════════════════════════════════════════════════════
  PASSO 4: CONVERTER EXTENSÃO (SE NECESSÁRIO)
═══════════════════════════════════════════════════════════════════════

WINDOWS:
1. Clique com botão direito na imagem
2. Abrir com → Paint ou Fotos
3. Arquivo → Salvar Como
4. Em "Tipo", escolha: JPEG
5. Digite o nome exato: IMG_1319(5).jpeg
6. Clique em "Salvar"

MAC:
1. Abra a imagem com Preview
2. File → Export
3. Format: JPEG
4. Name: IMG_1319(5).jpeg
5. Click "Save"

LINUX:
Use o comando:
convert original.jpg IMG_1319(5).jpeg

ONLINE (qualquer sistema):
- Use sites como: cloudconvert.com, convertio.co
- Upload da imagem
- Escolha formato JPEG
- Download com nome correto

═══════════════════════════════════════════════════════════════════════
  PROBLEMAS COMUNS E SOLUÇÕES
═══════════════════════════════════════════════════════════════════════

PROBLEMA: Imagem não aparece (ícone quebrado 🖼️❌)
SOLUÇÃO: Verifique o nome exato do arquivo

PROBLEMA: Imagem aparece distorcida
SOLUÇÃO: Tamanho muito pequeno - use imagens maiores (mín. 1000px)

PROBLEMA: Imagem aparece cortada
SOLUÇÃO: Normal - o CSS faz crop automático para fit

PROBLEMA: Site lento para carregar
SOLUÇÃO: Comprima as imagens (use tinypng.com ou compressor.io)

PROBLEMA: Extensão .jpg mas site pede .jpeg
SOLUÇÃO: Renomeie manualmente ou converta
