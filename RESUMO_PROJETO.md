### 📄 Páginas e Seções

1. **Header/Navegação**
   - Logo GT DRINKS
   - Menu fixo com scroll effect
   - Menu mobile responsivo
   - Active state nos links

2. **Hero Section (Banner Principal)**
   - Background com imagem de drinks
   - Título impactante
   - 2 CTAs (Call-to-Actions)
   - Scroll indicator animado

3. **Sobre a GT DRINKS**
   - Apresentação da empresa
   - Contadores animados (eventos, drinks, satisfação)
   - Espaço para imagem

4. **Seção Fundador (Thiago)**
   - Biografia do responsável
   - Foto profissional
   - Citação/filosofia

5. **Serviços**
   - 6 cards de serviços
   - Ícones personalizados
   - Hover effects
   - Descrições detalhadas

6. **Galeria**
   - Sistema de filtros (Todos, Drinks, Eventos, Bar Setup)
   - Grid responsivo
   - Transições suaves
   - Placeholders para imagens

7. **Carta de Drinks**
   - Sistema de abas (Clássicos, Autorais, Tropicais, Sem Álcool)
   - 15+ drinks incluídos
   - Layout organizado
   - Fácil de adicionar novos drinks

8. **Diferenciais**
   - 6 diferenciais da empresa
   - Ícones destacados
   - Animações ao scroll

9. **Formulário de Orçamento**
   - Validação de campos
   - Máscara de telefone automática
   - Labels animadas
   - Integração com WhatsApp
   - Design moderno

10. **Rodapé**
    - Informações de contato
    - Links rápidos
    - Redes sociais
    - Copyright

### Fase 1: Configuração Básica (30 min)
1. Abrir `index.html` no navegador
2. Substituir informações de contato
3. Configurar WhatsApp
4. Atualizar redes sociais

### Fase 2: Adicionar Conteúdo (2 horas)
1. Escrever biografia do Thiago
2. Revisar textos das seções
3. Adicionar drinks autorais
4. Completar informações

### Fase 3: Adicionar Imagens (1 hora)
1. Preparar fotos (compressão/redimensionamento)
2. Adicionar hero-bg.jpg e favicon.png
3. Adicionar fotos da galeria
4. Substituir placeholders

### Fase 4: Testes (1 hora)
1. Testar em diferentes dispositivos
2. Verificar todos os links
3. Testar formulário
4. Validar responsividade

### Fase 5: Publicação (30 min)
1. Criar repositório no GitHub
2. Fazer upload dos arquivos
3. Ativar GitHub Pages
4. Testar site publicado
